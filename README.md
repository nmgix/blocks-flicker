# Моргающие компоненты

Пришла небольшая идея моргающих блоков переходящих из состоний в состояния.

Планировался пул таймеров которые будут выделены под каждый тип состояния и кол-во таймеров будет активно имзеняться чтобы покрыть требования элементов. Пока скрутил до пары таймеров следящих вообще за всеми компонентами.

Рендер one-state элементов бзе таймеров (просто анимации), 500шт ест ~30Мб<
